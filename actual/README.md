# 實登查詢分析系統

純前端、無後台。核心是 **DuckDB-Wasm**(瀏覽器內執行 SQL 查詢 parquet)+ **Vue 3**(CDN,無需打包),整個查詢運算都在使用者瀏覽器裡跑，你只需要把靜態檔案丟到 GitHub Pages 之類的靜態空間。

## 檔案結構

```
index.html                   ← 整個應用程式(單一檔案)
data/連江縣.parquet            ← 範例資料，開啟即可測試
data/common_zone_rules.json  ← 重劃區判斷規則
```

## 重劃區規則(common_zone_rules.json)

結構是 `縣市 → 鄉鎮市區 → 重劃區名稱 → 地段規則(regex, 用 | 分隔多個段名)`：

```json
{
  "桃園市": {
    "桃園區": {
      "中路": "中路一段|中路二段|中路三段"
    }
  }
}
```

載入資料時,系統會依這份規則把每一筆交易的「土地位置」+「地號」拿去比對，符合就標記對應的重劃區名稱，變成篩選面板裡的「重劃區」選項。找不到規則的縣市/鄉鎮市區、或段名沒對到任何規則的交易，重劃區會是空值(不會出現在篩選清單裡，但資料本身還在)。

**要新增或調整規則**，直接編輯 `data/common_zone_rules.json`，不用碰 `index.html`。同一個鄉鎮市區內如果有段名同時出現在兩個重劃區規則裡(這份範例裡「石頭段」就同時出現在中壢站前跟中壢後站),系統採「json 裡先出現的規則優先」，建議規則盡量讓段名不要重複，或把比較精確/範圍小的規則放前面。

## 本機測試

瀏覽器基於安全限制，`file://` 直接開啟 `index.html` 沒辦法用 fetch 讀取 `./data/*.parquet`(CORS 限制)，**一定要用本機伺服器**:

```bash
cd 這個資料夾
python3 -m http.server 8000
```

然後開 `http://localhost:8000`。畫面右上角選單會自動偵測 `data/` 底下哪些檔案存在(用 HEAD request 檢查),找到的第一個會自動載入。

也可以不管檔案配置，直接用「上傳 Parquet」按鈕挑本機任一個 `.parquet` 檔案測試，不用先放進 `data/` 資料夾。

## 部署到 GitHub Pages / 你的網域

1. 把 `index.html` 和 `data/` 資料夾一起上傳
2. 打開 `index.html`,找到最上面的 `DATASET_CONFIG` 這段(第一個 `<script type="module">` 區塊開頭):

```js
const DATASET_CONFIG = [
  { label: '連江縣（範例）', path: './data/連江縣.parquet' },
  { label: '全部縣市（all）', path: './data/all.parquet' },
  { label: '常用資料（freq）', path: './data/freq.parquet' },
  // { label: '台北市', path: './data/台北市.parquet' },
];
```

3. 依你實際的縣市分檔情況新增/刪除項目,把對應的 parquet 檔案放進 `data/` 資料夾即可。找不到的檔案下拉選單會顯示「找不到檔案」並自動 disable,不會噴錯。

> 因為是純前端讀檔，`all.parquet` 如果檔案很大，建議依 `縣市`欄位排序過(讓 duckdb 的 range request 命中率更高，不用整個下載)。

## 功能

- **交易標的快速篩選**:一鍵切「一般房屋買賣」(無車位+有車位)、「土地」、「建物(未確認是否預售)」、「全部」,也可以自己勾細項
- **縣市 / 鄉鎮市區 / 重劃區 / 建物型態** 多選篩選(縣市篩選只在資料含多縣市時出現,例如載入 all.parquet；重劃區依 common_zone_rules.json 動態產生)
- **交易年、總價、單價、建物坪數** 區間篩選
- **單價指標可切換**:「純單價」涵蓋土地+建物,「每坪單價」只有建物適用(土地為空值)
- **資料品質**:預設排除「是否排除=true」(對應你資料裡「價格參考性=低」的 62 筆特殊交易)
- **統計卡片**:符合筆數(印章樣式)、總價中位數/平均、單價中位數/平均
- **走勢圖**:依交易年的單價趨勢 + 成交量長條
- **建物型態分布圖**:各型態均價 + 筆數
- **交易明細表**:分頁瀏覽,可依目前篩選條件匯出 CSV(含 UTF-8 BOM,Excel 開啟中文不會亂碼)

## 已知限制 / 之後可以擴充

- 目前一次只查詢一份資料檔(縣市檔或 all.parquet 擇一),還沒做「同時載入多份 parquet 合併查詢」;如果你的 all.parquet 已經涵蓋全部縣市，這其實已經足夠
- 樓層、屋齡等欄位還沒加進篩選面板，之後有需要可以照現有的區間篩選模式(如「建物坪數」那段)直接複製擴充
- `建案名稱` 欄位在連江縣資料裡目前是全空的(這個縣市大概真的沒建案登記),關鍵字搜尋在其他縣市檔案應該會吃到資料

如果部署後畫面跑不動或 DuckDB 初始化失敗(通常是瀏覽器版本太舊或網路擋了 jsdelivr CDN),把 console 的錯誤訊息貼給我,我可以繼續幫你除錯。
